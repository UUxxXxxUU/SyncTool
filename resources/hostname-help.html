在需要连接的那台远程电脑上查看

Windows 10 / Windows 11：打开“开始 → 设置 → 系统 → 关于”，找到“设备名称”。例如 DESKTOP-U6HE6A0。

通用方法：按 Win + R，输入 cmd 并回车；再输入 hostname 并回车，下一行就是主机名。

图中名称仅为示例，图片为操作示意图。请填写远程电脑实际显示的名称。

填入共享目录

主机名只是共享路径的一部分。例如主机名为 DESKTOP-U6HE6A0，共享名为 share，则路径可以是：

\\DESKTOP-U6HE6A0\share\LHJ\Release

“显示名称”用于备注，可填写“实验室电脑”等；连接使用“共享目录”中的主机名或 IP。扫描到设备后，仍需填写远程电脑真实存在的共享名和目录。

如果主机名无法连接，可尝试该电脑的 IP 地址，并检查是否处于同一网络、共享权限及防火墙设置。
